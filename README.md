# Rohlík přehled — zdraví & úspory

Personalizovaný dashboard analyzující objednávky z Rohlik.cz s doporučeními pro zdraví a úspory.

## Živá verze

Po aktivaci GitHub Pages bude dashboard dostupný na:
**https://ishalkin.github.io/rohlik-prehled/**

## Aktivace GitHub Pages

1. Otevřete **Settings** → **Pages**
2. Source: `Deploy from a branch`
3. Branch: `main` / folder: `/ (root)`
4. Save

Obvykle do 1–2 minut běží.

## Data

- Období: 1. 4. – 27. 5. 2026
- 4 objednávky, celkem 3 871 Kč
- Všechny analýzy běží přímo v prohlížeči (statický HTML + Chart.js z CDN)
